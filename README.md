# AdminBinder

Для запуска `binder.ahk` нужен [AutoHotkey v2](https://www.autohotkey.com/). Откройте файл через AutoHotkey v2 после установки.

Существующие `res/Settings.ini`, `res/Shortcuts.tsv` и `Punishment.txt` можно использовать с этой версией. При первом запуске биндер создаёт отсутствующие личные файлы.

В верхнем разделе «Кликер» включите его, нажмите на поле кнопки и затем на нужную клавишу или кнопку мыши (включая боковые). Укажите интервал от 10 до 10000 мс и нажмите «Сохранить и применить». Кликер работает при удержании кнопки в GTA5 или RAGE MP.
